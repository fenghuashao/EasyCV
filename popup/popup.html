Quick Start

  1. Return to the page and select text. Use Ctrl+C / ⌘C to copy and Ctrl+V / ⌘V to paste.
  2. If normal unlock does not help, try Force Mode in Advanced Options.
  3. If a website stops working correctly, add it in Settings → Site Exclusions.

Browser pages and the Chrome Web Store cannot be unlocked. Text inside images or scans requires a separate OCR tool.
