# EasyCV 功能验证指南

## 🎯 指南定位

本文档是测试领域的 **Reference Document**，用于指导当前版本的**手工验证执行**。

本文档不单独定义支持范围。浏览器支持范围、发布前门槛和测试层次，以 [测试计划](./测试计划.md) 为准。

## 📋 验证前准备

### 验证环境

- 已安装 EasyCV 扩展
- 可访问 `test/fixtures/copy-paste.html`
- 可打开浏览器开发者工具

### 验证前检查

1. 确认插件已成功加载
2. 确认当前分支构建正常
3. 先运行：

```bash
npm run docs:check
npm run build
```

## ✅ P0 手工验证流程

以下流程对应发布前最少应完成的手工验证。

### 1. 插件加载验证

**目标**：确认扩展可以正常加载

**步骤**：
1. 打开扩展管理页面
2. 加载 EasyCV 项目目录
3. 检查工具栏图标是否出现

**预期结果**：
- 插件成功加载
- 无明显报错

### 2. Popup 基础验证

**目标**：确认 Popup 可以正常显示与交互

**步骤**：
1. 点击浏览器工具栏中的 EasyCV 图标
2. 检查 Popup 是否正常显示
3. 观察主开关、复制/粘贴相关控件和强力模式控件

**预期结果**：
- Popup 正常显示
- 状态信息可见
- 主要控件可点击

### 3. 文本选择限制解除

**目标**：确认插件能解除基础文本选择限制

**测试页面**：`test/fixtures/copy-paste.html`

**步骤**：
1. 打开 `test/fixtures/copy-paste.html`
2. 在插件关闭状态下尝试选择受限文本
3. 启用插件
4. 再次尝试选择文本

**预期结果**：
- 禁用时限制存在
- 启用后可以正常选择文本

### 4. 右键菜单恢复

**目标**：确认插件能恢复受限右键菜单

**步骤**：
1. 在受限区域右键点击
2. 观察插件禁用状态下的行为
3. 启用插件后再次尝试

**预期结果**：
- 启用后右键菜单恢复可用

### 5. 复制快捷键恢复

**目标**：确认 `Ctrl+C` 复制恢复正常

**步骤**：
1. 选择受限文本
2. 禁用状态下尝试复制
3. 启用插件
4. 再次复制并到其他区域粘贴验证

**预期结果**：
- 启用后复制成功

### 6. 多标签页基础同步

**目标**：确认状态变更不会只停留在单个标签页

**步骤**：
1. 打开两个标签页
2. 在一个标签页切换插件状态
3. 观察另一个标签页的实际效果或状态变化

**预期结果**：
- 状态更新能够被正确传播

## ⚡ P1 建议验证流程

时间允许时，建议继续执行以下手工验证。

### 7. 强力模式

**步骤**：
1. 打开限制较复杂的页面
2. 先启用基础功能
3. 再启用强力模式
4. 比较两者效果

**预期结果**：
- 强力模式在复杂场景下表现更强

### 8. 设置页面

**步骤**：
1. 打开设置页面
2. 修改复制 / 粘贴 / 强力模式等设置
3. 刷新或重新打开
4. 检查是否持久化

**预期结果**：
- 设置保存正常

### 9. 自动开启列表

**步骤**：
1. 在设置页添加测试域名
2. 访问该域名页面
3. 检查是否自动启用
4. 删除后再次验证

**预期结果**：
- 自动开启行为符合预期

## 🌐 真实页面验证建议

除了 `test/fixtures/copy-paste.html`，建议至少选 1-2 个真实页面进行验证：

- 新闻网站
- 文档网站
- 学术网站
- 博客页面

关注点：

- 是否真的解除复制/选择限制
- 是否引入明显副作用
- 强力模式是否影响页面正常交互

## 🛡️ 异常与风险观察

验证时建议顺手观察以下风险：

- Popup 是否出现明显报错
- 页面切换时是否有异常状态残留
- 快速切换开关时是否出现卡死
- 页面刷新后状态是否符合预期
