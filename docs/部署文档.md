## 📦 打包流程

### 自动化打包脚本
```javascript
// scripts/package.js
const fs = require('fs');
const path = require('path');
const archiver = require('archiver');

async function createPackage() {
  const manifest = JSON.parse(fs.readFileSync('dist/manifest.json', 'utf8'));
  const version = manifest.version;
  const packageName = `EasyCV-v${version}.zip`;
  
  const output = fs.createWriteStream(packageName);
  const archive = archiver('zip', { zlib: { level: 9 } });
  
  output.on('close', () => {
    console.log(`✅ 打包完成: ${packageName} (${archive.pointer()} bytes)`);
  });
  
  archive.pipe(output);
  archive.directory('dist/', false);
  await archive.finalize();
}

createPackage().catch(console.error);
```

### 版本管理

#### 语义化版本控制
- **主版本号**: 不兼容的API修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

#### 版本更新脚本
```bash
#!/bin/bash
# scripts/bump-version.sh

VERSION_TYPE=${1:-patch}  # major, minor, patch

# 更新 package.json
npm version $VERSION_TYPE --no-git-tag-version

# 更新 manifest.json
NEW_VERSION=$(node -p "require('./package.json').version")
jq ".version = \"$NEW_VERSION\"" manifest.json > manifest.tmp.json
mv manifest.tmp.json manifest.json

echo "✅ 版本已更新至: $NEW_VERSION"
```

## 🚀 发布流程

### Chrome Web Store 发布

#### 准备工作
1. **开发者账号**: 注册 Chrome Web Store 开发者账号
2. **应用图标**: 准备各尺寸图标文件
3. **应用描述**: 准备商店页面内容
4. **隐私政策**: 准备隐私政策文档

#### 发布步骤
1. **登录开发者控制台**
   - 访问 [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/)
   - 使用开发者账号登录

2. **创建新应用**
   - 点击 "新增项目"
   - 上传打包好的 ZIP 文件
   - 填写应用信息

3. **配置应用详情**
   ```
   应用名称: EasyCV - 解除网页复制粘贴限制
   简短描述: 一键解除网页复制粘贴限制，提升工作效率
   详细描述: [详细功能介绍]
   类别: 生产力工具
   语言: 中文(简体)
   ```

4. **上传资源文件**
   - 应用图标: 128x128px
   - 截图: 1280x800px 或 640x400px
   - 宣传图片: 440x280px

5. **隐私设置**
   - 数据使用说明
   - 隐私政策链接
   - 权限说明

6. **提交审核**
   - 检查所有信息
   - 提交审核
   - 等待审核结果（通常1-3个工作日）

### Edge Add-ons 发布

#### 发布流程
1. 访问 [Microsoft Edge Add-ons](https://partner.microsoft.com/dashboard/microsoftedge/)
2. 使用 Microsoft 开发者账号登录
3. 上传相同的扩展包
4. 填写类似的应用信息
5. 提交审核

## 🔄 持续集成/持续部署 (CI/CD)

### GitHub Actions 配置
```yaml
# .github/workflows/build-and-test.yml
name: Build and Test

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        cache: 'npm'
    
    - name: Install dependencies
      run: npm ci
    
    - name: Run linter
      run: npm run lint
    
    - name: Run tests
      run: npm run test:coverage
    
    - name: Build extension
      run: npm run build
    
    - name: Upload coverage
      uses: codecov/codecov-action@v3
```

### 自动发布配置
```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
    
    - name: Install dependencies
      run: npm ci
    
    - name: Build and package
      run: npm run package
    
    - name: Create Release
      uses: actions/create-release@v1
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      with:
        tag_name: ${{ github.ref }}
        release_name: Release ${{ github.ref }}
        draft: false
        prerelease: false
```

## 🔧 故障排除

### 常见部署问题

#### 构建失败
```bash
# 清理并重新构建
npm run clean
npm install
npm run build
```

#### 打包错误
- 检查 manifest.json 格式
- 验证文件路径正确性
- 确认所有依赖文件存在

#### 审核被拒
- 检查权限申请是否合理
- 确认隐私政策完整
- 验证功能描述准确
- 检查是否违反商店政策

### 回滚策略
```bash
# 紧急回滚到上一版本
git checkout v1.0.0
npm run build
npm run package
# 重新提交到商店
```
