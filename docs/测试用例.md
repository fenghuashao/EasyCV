# EasyCV 测试用例文档

## 📋 文档概述

**项目名称**: EasyCV - 解除网页复制粘贴限制插件  
**测试版本**: V1.0  
**文档版本**: 1.0.0  
**最后更新**: 2024年12月

## 🎯 测试用例分类

### 测试优先级
- **P0**: 核心功能，必须通过
- **P1**: 重要功能，影响用户体验
- **P2**: 一般功能，可延后修复
- **P3**: 边缘功能，影响较小

### 测试类型
- **功能测试**: 验证功能需求实现
- **界面测试**: 验证UI/UX设计
- **兼容性测试**: 验证跨浏览器、跨网站兼容性
- **性能测试**: 验证响应时间和资源占用
- **安全测试**: 验证权限控制和数据安全

## 🔧 核心功能测试用例 (P0)

### TC001: 插件安装与加载
**测试目标**: 验证插件能够正确安装和加载

**前置条件**:
- Chrome 88+ 浏览器
- 开发者模式已开启

**测试步骤**:
1. 打开Chrome扩展管理页面 (`chrome://extensions/`)
2. 点击"加载已解压的扩展程序"
3. 选择EasyCV项目根目录
4. 确认加载

**预期结果**:
- 插件成功加载，无错误提示
- 工具栏显示EasyCV图标
- 图标状态为默认状态（灰色）

**测试数据**: 无
**优先级**: P0
**测试类型**: 功能测试

---

### TC002: 插件启用/禁用功能
**测试目标**: 验证插件启用和禁用功能正常工作

**前置条件**:
- 插件已成功安装
- 访问任意网页

**测试步骤**:
1. 点击工具栏中的EasyCV图标
2. 观察弹出窗口状态
3. 点击"启用EasyCV"切换开关
4. 观察图标和状态变化
5. 再次点击切换开关禁用

**预期结果**:
- 弹出窗口正确显示当前状态
- 启用时图标变为绿色，状态显示"已启用"
- 禁用时图标变为灰色，状态显示"已禁用"
- 状态变化实时反映在界面上

**测试数据**: 无
**优先级**: P0
**测试类型**: 功能测试

---

### TC003: 文本选择限制解除
**测试目标**: 验证插件能够解除网页文本选择限制

**前置条件**:
- 插件已安装并启用
- 访问有文本选择限制的网页

**测试网站示例**:
- 某些新闻网站
- 学术论文网站
- 付费内容网站

**测试步骤**:
1. 访问有选择限制的网页
2. 尝试选择文本（应该被限制）
3. 启用EasyCV插件
4. 再次尝试选择文本
5. 验证选择功能是否恢复

**预期结果**:
- 启用前：无法选择文本或选择受限
- 启用后：可以正常选择文本
- 选择的文本可以复制到剪贴板

**测试数据**: 限制网站URL列表
**优先级**: P0
**测试类型**: 功能测试

---

## ⚡ 性能测试用例 (P2)

### TC016: 响应时间测试
**测试目标**: 验证插件操作的响应时间符合要求

**性能要求**:
- 启用/禁用响应时间 < 100ms
- 页面分析时间 < 500ms
- 内存占用 < 10MB

**测试步骤**:
1. 使用性能监控工具
2. 测试插件启用/禁用时间
3. 测试页面分析处理时间
4. 监控内存使用情况
5. 测试长时间运行稳定性

**预期结果**:
- 响应时间符合要求
- 内存占用在合理范围
- 长时间运行稳定
- 无内存泄漏

**测试数据**: 性能基准数据
**优先级**: P2
**测试类型**: 性能测试
