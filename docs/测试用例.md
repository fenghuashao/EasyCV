# EasyCV 测试用例文档

## 📋 文档概述

**项目名称**: EasyCV - 解除网页复制粘贴限制插件  
**测试版本**: V1.0  
**文档版本**: 1.1.0  
**最后更新**: 2026年8月

## 🎯 本文档职责

本文档是测试领域的 **Source Document**，用于维护当前版本的测试用例库与回归清单。

本文档**不单独定义支持范围**。浏览器支持范围、测试层次和发布前门槛，以 [测试计划](./测试计划.md) 为唯一真相来源。

当前仓库的测试层次、执行方式和发布前门槛，以 [测试计划](./测试计划.md) 为准；本文档只维护测试项与回归清单。

## 1.1.2 权限回归补充

使用同一 `test/permission-regression.mjs` 对保留的 1.1.1 与解压后的 1.1.2 发布 ZIP 执行限制解除、Popup 设置写入、强力模式、动态 DOM、重复注入、标签切换、自动启用和排除恢复测试。原生 Chrome 操作、升级持久化与真实站点的人工清单及结果见 [权限整改报告](../EASYCV-1.1.2-PERMISSION-FIX.md)。

## 🎯 测试优先级

2026-11-03 后续优化的回归范围（未打包，不替代锁定 1.1.2 验收）：

- `test/unit/popup-ux.test.mjs` 使用真实 Content Script 返回的状态信封驱动 Popup，覆盖首次自动开启、部分/关闭、全局关闭、排除、内部页/商店、连接缺失等状态。
- 复制开关关闭、开启及缺少字段时，分别提示关闭、需手动复制验证、查询失败；不能显示“复制成功”。
- 帮助展开/收起只操作本地面板；反馈链接必须指向真实仓库，不能自动包含当前 URL、查询令牌、私人片段或浏览器明细。
- `test/popup-ux-regression.mjs` 在隔离浏览器验证中英文实际渲染、页面消息校验/接收、开关后的状态、排除页与不支持页、帮助可访问性及380px宽度；最终轮在测试中截取创建反馈草稿的 API 调用，不实际导航或提交。
- 对本地限制页进行真实复制粘贴 smoke。测试证据及平台边界见 [本轮优化报告](../EASYCV-OPTIMIZATION-20261103.md)。

- **P0**：核心功能，发布前必须通过
- **P1**：重要功能，应尽量覆盖
- **P2**：一般功能，按时间安排
- **P3**：探索性或边缘场景

## 🔧 核心功能测试用例（P0）

### TC001：插件安装与加载

**目标**：验证插件能够正确安装和加载

**前置条件**：
- Chrome 或 Edge 88+
- 开发者模式已开启

**测试步骤**：
1. 打开扩展管理页面
2. 点击“加载已解压的扩展程序”
3. 选择 EasyCV 项目根目录
4. 观察加载结果

**预期结果**：
- 插件成功加载
- 工具栏显示 EasyCV 图标
- 无明显加载错误

**优先级**：P0  
**测试类型**：功能测试

---

### TC002：插件启用 / 禁用

**目标**：验证插件启用和禁用流程正常

**前置条件**：
- 插件已安装
- 访问任意页面

**测试步骤**：
1. 点击 EasyCV 图标打开 Popup
2. 观察当前状态
3. 切换主开关
4. 再次切换恢复

**预期结果**：
- Popup 正常显示当前状态
- 开关切换后状态实时更新
- 图标状态与开关状态一致

**优先级**：P0  
**测试类型**：功能测试

---

### TC003：文本选择限制解除

**目标**：验证插件能够解除文本选择限制

**前置条件**：
- 插件已安装
- 访问 `test-page.html` 或有文本限制的真实页面

**测试步骤**：
1. 在插件禁用状态下尝试选择文本
2. 启用插件
3. 再次尝试选择文本

**预期结果**：
- 禁用时限制可复现
- 启用后可以正常选择文本

**优先级**：P0  
**测试类型**：功能测试

---

### TC004：右键菜单恢复

**目标**：验证插件能够恢复被限制的右键菜单

**测试步骤**：
1. 在受限制区域右键点击
2. 观察禁用状态下的行为
3. 启用插件后再次右键点击

**预期结果**：
- 禁用时限制可复现
- 启用后右键菜单恢复可用

**优先级**：P0  
**测试类型**：功能测试

---

### TC005：复制快捷键恢复

**目标**：验证插件能够恢复复制快捷键

**测试步骤**：
1. 选择受限制文本
2. 在禁用状态下尝试 `Ctrl+C`
3. 启用插件
4. 再次尝试复制并到其他位置粘贴验证

**预期结果**：
- 禁用时复制受限
- 启用后复制快捷键正常工作

**优先级**：P0  
**测试类型**：功能测试

---

### TC006：基础状态同步

**目标**：验证状态切换后页面与 Popup 之间保持一致

**测试步骤**：
1. 打开至少两个标签页
2. 在一个标签页通过 Popup 切换状态
3. 观察当前页和另一标签页表现

**预期结果**：
- 状态变更能同步反映到相关页面
- 不出现明显卡死或错误提示

**优先级**：P0  
**测试类型**：功能测试

## ⚡ 重要功能测试用例（P1）

### TC007：强力模式启用

**目标**：验证强力模式在复杂限制场景下有效

**测试步骤**：
1. 访问较复杂的限制页面
2. 启用基础功能并观察效果
3. 启用强力模式
4. 对比普通模式与强力模式效果

**预期结果**：
- 强力模式可处理更多限制场景
- 状态切换无明显错误

**优先级**：P1  
**测试类型**：功能测试

3. 刷新页面或重新打开设置页

**预期结果**：

**优先级**：P1  
**测试类型**：功能测试

**目标**：验证自动开启列表的添加、删除和生效

3. 观察是否自动启用
4. 删除域名后再次验证

**预期结果**：
- 域名可以成功添加和删除
- 自动开启行为符合预期

**优先级**：P1

## 🔒 安全与稳定性测试用例

### TC011：权限合理性检查

**目标**：确认插件声明和使用的权限与当前实现一致

**测试步骤**：
1. 查看 `manifest.json`
2. 对照当前功能路径检查权限用途
3. 验证无明显多余权限声明

**预期结果**：
- 权限与当前功能匹配
- 未发现明显越权声明

**优先级**：P1  
**测试类型**：安全测试

---

### TC012：异常情况处理

**目标**：验证页面切换、快速操作和异常状态下的基本稳定性

**测试步骤**：
1. 页面加载中快速切换插件状态
2. 快速多次切换开关
3. 刷新页面后再次验证

**预期结果**：
- 不出现明显崩溃
- 不出现阻塞性报错
- 用户仍可恢复到正常状态

**优先级**：P1  
**测试类型**：稳定性测试
