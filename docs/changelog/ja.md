# EasyCV 更新履歴

[简体中文](../../CHANGELOG.md) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](./en.md)

これはユーザー向けのバージョン概要です。より詳しい開発・テストの履歴は[简体中文の更新履歴](../../CHANGELOG.md)に記載しています。

## 1.1.3 — ストア更新日 2026-11-04

- 製品内にデータの説明を追加しました。ページ上の機能を有効にする前、および旧データを移行する前に同意が必要です。
- 英語、简体中文、繁體中文、日本語に対応しました。対応していないブラウザー言語では英語を表示します。
- ページの状態表示を改善し、内蔵ヘルプを追加しました。「コピー状態を確認」は設定の確認であり、クリップボードの読み書きや実際のコピーの成否の確認は行いません。
- サイトのルールを編集・保存・キャンセルできるようにし、設定インポートの検証を強化しました。端末内の設定の復元、移行の案内、より明確な保存エラーも追加しました。除外設定と全体スイッチは自動有効化ルールより優先されます。
- 有効化回数と簡略化された診断情報を端末内に保存し、ドメイン別のアクセス記録を新たに追加しません。旧データの処理は[プライバシーポリシー](../privacy/ja.md)をご覧ください。
- フィードバックでは GitHub issue の下書きを開き、現在のページアドレスの自動添付や自動送信を行いません。
- 機能をオフにした後のページのイベントハンドラーとスタイルの復元を改善しました。状態を確認できない場合はページへの処理を停止します。

ストアのパッケージは 2026-11-08 に確認しました。manifest と各言語の拡張機能の説明文を除き、実行ファイルはリポジトリと一致します。リポジトリの manifest は引き続き 1.1.2 です。ストアのバージョンだけでは、個々のインストールが更新済みであることは確認できません。

## 1.1.2 — ローカル候補版、2026-11-01 と 2026-11-03

- 候補版から未使用の `scripting` と重複する `activeTab` 権限を削除し、`storage`、`contextMenus`、`<all_urls>` を維持しました。
- ポップアップのスイッチと既存ページの同期、初回アクセス時のサイトルール、強力モード設定の保存を修正しました。機能をオフにしたときにページのハンドラーとスタイルを復元します。
- 1.1.2 の項目はローカル候補パッケージとそのテストの記録であり、1.1.2 のストア公開や同一 ID での更新検証を示すものではありません。

## 1.1.1 — 2026-08-31

- 「拡張機能について」からリポジトリ、問題報告、ユーザードキュメントにアクセスできるようにし、リポジトリと Wiki を公開しました。
- デバッグログを減らし、エクスポートした設定のバージョン表示を修正し、ポップアップが現在のページを速やかに確認・表示するよう改善しました。
- 実サイトの回帰テスト基盤を更新し、テスト環境の影響を受けた旧結果を置き換えました。

## 1.1.0 — 2026-08-10

- サイトの除外リストを追加しました。一般的なアカウントのログインドメインが既定で登録され、編集できます。除外はサブドメインにも適用され、設定のエクスポート・インポートに含まれます。
- ポップアップと自動有効化の管理を更新し、英語と简体中文に対応するとともに、Shadow DOM とシングルページナビゲーションのサポートを改善しました。
- ページの通常操作への影響を減らすためイベントの遮断を限定し、従来のメッセージ、状態復元、ストレージの問題を修正しました。状態アイコンとプロジェクトのチェックも追加しました。

インストール、制限、データ処理については[ユーザーガイド](../user-guide/ja.md)と[プライバシーポリシー](../privacy/ja.md)をご覧ください。
