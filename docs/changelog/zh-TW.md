# EasyCV 更新紀錄

[简体中文](../../CHANGELOG.md) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](./en.md)

此處為面向使用者的版本摘要。[簡體中文更新日誌](../../CHANGELOG.md)保留較完整的工程與測試歷史。

## 1.1.3 — 商店更新日期 2026-11-04

- 新增產品內資料說明；啟用網頁功能或移轉舊資料前，須先取得同意。
- 支援英文、簡體中文、繁體中文及日文；沒有對應翻譯的瀏覽器語言會顯示英文。
- 更準確地顯示頁面狀態並提供內建說明。「檢查複製狀態」只檢查設定，不讀寫剪貼簿，也不驗證實際複製是否成功。
- 網站規則可編輯、儲存或取消，設定匯入驗證更嚴謹，並提供本機還原、移轉提示及更明確的儲存錯誤。排除清單與總開關優先於自動啟用規則。
- 啟用次數與簡化診斷保存在本機，不再新增按網域記錄的造訪資料；歷史資料的處理方式請見[隱私權政策](../privacy/zh-TW.md)。
- 意見回饋會開啟 GitHub issue 草稿，不會自動附上目前頁面網址或自動提交。
- 改善停用功能後網頁事件處理常式和樣式的還原；無法確認狀態時停止干預頁面。

商店套件於 2026-11-08 核對。除 manifest 和各語言的擴充功能簡介外，其供擴充功能運作的檔案與當時的儲存庫一致；儲存庫 manifest 仍標示 1.1.2。商店版本狀態本身不能證明某個安裝已完成升級。

## 1.1.2 — 本機候選版，2026-11-01 與 2026-11-03

- 從候選版移除未使用的 `scripting` 與多餘的 `activeTab` 權限；保留 `storage`、`contextMenus` 和 `<all_urls>`。
- 修復彈出視窗開關與既有頁面的同步、首次造訪的網站規則及強力模式設定保存；關閉功能後還原頁面處理常式與樣式。
- 1.1.2 項目描述本機候選套件及其測試，不代表 1.1.2 已在商店發佈，也不代表同 ID 升級已完成驗證。

## 1.1.1 — 2026-08-31

- 「關於」頁連結到儲存庫、問題追蹤與使用文件，並公開儲存庫及 Wiki。
- 減少除錯日誌，修正匯出設定的版本號，並讓彈出視窗及時檢查和顯示目前頁面。
- 更新真實網站回歸測試基礎設施，取代受測試環境影響的舊結果。

## 1.1.0 — 2026-08-10

- 新增網站排除清單，預設排除常見帳號登入網域且可自行編輯；排除涵蓋子網域，並包含於設定匯出與匯入。
- 更新彈出視窗與自動啟用管理，加入英文和簡體中文介面，改善 Shadow DOM 與單頁導覽支援。
- 縮小事件攔截範圍以減少對網頁正常互動的影響，修復歷史訊息、狀態還原及儲存問題，並新增狀態圖示和專案檢查。

安裝方式、限制與資料處理請見[使用手冊](../user-guide/zh-TW.md)和[隱私權政策](../privacy/zh-TW.md)。
