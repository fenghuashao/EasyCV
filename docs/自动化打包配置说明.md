# EasyCV 自动化打包配置说明

## 📋 概述

EasyCV 项目已完成自动化打包配置，提供了完整的构建、打包、部署流程。通过 npm 脚本可以轻松执行各种自动化任务。

## 🛠️ 配置组件

### 1. 核心脚本文件

| 文件 | 功能 | 描述 |
|------|------|------|
| `scripts/build.js` | 项目构建 | 复制源文件到 dist 目录，生成构建信息 |
| `scripts/package.js` | 项目打包 | 将构建结果打包为 ZIP 文件 |
| `scripts/clean.js` | 清理构建 | 清理临时文件和构建产物 |
| `scripts/bump-version.js` | 版本管理 | 自动更新版本号 |
| `scripts/deploy.js` | 自动化部署 | 完整的部署流程管理 |

### 2. NPM 脚本命令

#### 基础命令
```bash
# 开发模式
npm run dev

# 构建项目
npm run build

# 打包项目
npm run package

# 清理构建文件
npm run clean

# 完整发布流程
npm run release
```

#### 版本管理
```bash
# 更新补丁版本 (1.0.0 -> 1.0.1)
npm run bump:patch

# 更新次版本 (1.0.0 -> 1.1.0)
npm run bump:minor

# 更新主版本 (1.0.0 -> 2.0.0)
npm run bump:major
```

#### 自动化部署
```bash
# 完整部署流程
npm run deploy

# 更新版本并部署
npm run deploy:patch   # 补丁版本
npm run deploy:minor   # 次版本
npm run deploy:major   # 主版本

# 仅构建模式
npm run deploy:build-only

# 预览模式（不实际执行）
npm run deploy:dry-run
```

## 🚀 使用流程

### 日常开发
1. 修改代码
2. 执行 `npm run build` 构建项目
3. 手动加载扩展到浏览器测试

### 版本发布
1. 执行 `npm run deploy:minor` 更新版本并部署
2. 或分步执行：
   ```bash
   npm run bump:minor  # 更新版本
   npm run deploy      # 执行部署
   ```

### 快速打包
```bash
npm run release  # 清理 + 构建 + 打包
```

## 🔧 高级配置

### 自定义构建

修改 `scripts/build.js` 中的 `sourceFiles` 和 `sourceDirs` 配置：

```javascript
const sourceFiles = [
  'manifest.json',
  // 添加其他文件
];

const sourceDirs = [
  'background',
  'content',
  // 添加其他目录
];
```

### 自定义清理

修改 `scripts/clean.js` 中的清理配置：

```javascript
this.cleanDirs = [
  'dist',
  'node_modules/.cache',
  // 添加其他目录
];

this.cleanFiles = [
  'build-info.json',
  // 添加其他文件
];
```

### 部署选项

`scripts/deploy.js` 支持多种选项：

```bash
# 跳过测试
node scripts/deploy.js --skip-tests

# 跳过验证
node scripts/deploy.js --skip-validation

# 预览模式
node scripts/deploy.js --dry-run

# 仅构建
node scripts/deploy.js --build-only

# 仅打包
node scripts/deploy.js --package-only

# 清理并退出
node scripts/deploy.js --clean
```

## 🔍 故障排除

### 常见问题

1. **构建失败**
   - 检查源文件是否存在
   - 确认 `manifest.json` 格式正确

2. **打包失败**
   - 确保先执行构建
   - 检查 `dist` 目录是否存在

3. **清理错误**
   - 文件被占用时会跳过清理
   - 权限不足时会显示警告

### 调试模式

使用预览模式查看将要执行的操作：
```bash
npm run deploy:dry-run
```

## 📝 最佳实践

1. **版本管理**
   - 使用语义化版本号
   - 重大更新使用 major
   - 新功能使用 minor
   - 修复使用 patch

2. **发布流程**
   - 发布前先测试
   - 使用预览模式确认操作
   - 保留发布包备份

3. **文件管理**
   - 定期清理构建文件
   - 不要手动修改 dist 目录
   - 保持源代码整洁
