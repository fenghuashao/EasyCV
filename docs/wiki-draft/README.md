# Wiki 更新草稿

此目录保存面向用户的 GitHub Wiki 草稿，不代表线上 Wiki 已更新：

- `Home.md` 对应 Wiki 首页，提供四语言手册、隐私政策和更新日志入口。
- `User-Guide.md` 对应既有 `User Guide` 页面，保留原入口并引导读者选择语言。

链接指向 GitHub 仓库 `master` 分支。发布前先审核隐私及版本表述，确认四语言文件已经出现在目标分支，再单独更新 Wiki；最后从公开 Wiki 逐个打开链接并核对商店、政策及实际分发包。若变更后的内容不适用已分发版本，不得将其作为该版本的说明。无需在 Wiki 复制完整手册，避免维护两份正文。

本目录是可审阅草稿，不执行提交、推送、Wiki 发布或商店更新。
