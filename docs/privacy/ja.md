# EasyCV プライバシーポリシー

[简体中文](../../PRIVACY.md#easycv-隐私政策) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](../../PRIVACY.md#easycv-privacy-policy)

発効日：2026-11-03 ｜ 対象：EasyCV 1.1.1、および同じデータ処理方法を用いる 1.1.3 以降のバージョン

EasyCV は、制限のあるウェブページでコピー、貼り付け、文字選択、右クリックメニューを使用できるよう支援します。以下ではまず 1.1.3 の処理方法を説明します。1.1.1 との違いは「バージョン 1.1.1」をご覧ください。

## 1.1.3 のデータ処理

EasyCV には開発者のサーバー、テレメトリー、広告、リモートコードがなく、開発者にデータを送信するインターフェースもありません。以下の処理はすべてブラウザー内で行われます。

### ウェブサイトの内容

コピー、貼り付け、文字選択、右クリックの制限を検出・解除するため、拡張機能は閲覧する通常のページの構造、インラインイベントハンドラー、スタイルを処理し、必要に応じて拡張機能に同梱されたスクリプトをページに注入します。クリップボードの内容は読み取りも保存もせず、ページ本文、完全な閲覧アドレス、クエリパラメーターを診断情報に記録しません。

### 閲覧履歴とサイトルール

拡張機能は、サイトルールや除外リストとの照合、およびページの状態表示のために、**現在のページ**のアドレスまたはドメインを読み取ります。拡張機能自体は閲覧履歴を作成しません。

手動で設定したサイトルールと除外リストはブラウザーの `chrome.storage.sync` に保存され、入力したドメインを含みます。ブラウザーのアカウント設定に応じて、これらの設定が他の端末に同期される場合があります。この同期はブラウザーとそのサービス提供者が処理し、EasyCV 開発者のサーバーを経由しません。

### ユーザーの操作

旧バージョンはサイトの操作記録（ドメインと時刻）とサイト別の利用回数を同期ストレージに保存していました。1.1.3 はこれらの記録を新たに追加しません。更新時に過去のデータを端末内のバックアップに移行し（次節参照）、手動で削除するまで端末に保持します。

### 有効化回数、診断情報、端末内のコピー

- 有効化の合計回数、当日の回数、日付は、端末内の `chrome.storage.local` に保存され、この端末での表示にのみ使用されます。設定で記録をオフにできます。これらは実際にコピーできた回数や成功率ではありません。
- 直近最大 10 件の簡略化された診断情報が端末内に保存されます。固定のエラーコードとモジュール、および利用可能な場合は日時と拡張機能のバージョンのみを含みます。閲覧アドレス、ページ本文、クリップボードの内容、例外メッセージ、スタックは含みません。診断情報を自動アップロードするサービスはありません。
- 端末内に残った旧設定のコピーは、ユーザー自身でエクスポートし、明示的に復元できます。同期された設定が優先され、端末内のコピーで自動的に上書きされることはありません。

## 旧データと移行

旧バージョンは統計（サイト別の回数を含む）、サイトの操作記録、エラーの詳細、フィードバックの下書きを同期ストレージに保存していた可能性があります。更新後、製品内のデータ説明に明示的に同意した場合にのみ、拡張機能はページ上の機能を有効にして移行を開始します。まず過去の統計と操作記録を端末内にバックアップして検証し、対応する同期コピーの削除を試みます。旧診断情報は情報を削減し、旧フィードバックの下書き内容は破棄します。この移行で設定や手動のルールが削除されることはありません。同意前は旧データが同期ストレージに残る場合があります。

端末への書き込み、検証、同期ストレージの削除に失敗した場合、未処理の同期コピーは保持され、設定画面に再試行の案内が表示されます。ブラウザーアカウントの遠隔の履歴コピーや、旧バージョンが動作し続ける他の端末上のコピーがすぐに削除される保証はありません。

## 選択できること

設定で回数の記録をオフにしたり、サイトルールを編集・削除したりできます。「設定 → 詳細設定 → すべてのデータを削除」では、拡張機能の設定、ルール、端末内の回数、診断情報、旧データのバックアップを削除できます。記録をオフにしても新規記録を停止するだけで、既存の回数は自動的に削除されません。設定を残したい場合は先にエクスポートしてください。設定のエクスポートには旧バージョンの閲覧履歴や診断情報は含まれません。ストレージ操作に失敗した場合は、画面の案内に従って再試行してください。同期データや他の端末の状態はブラウザー自体の同期の仕組みに左右されます。

## ユーザーが開く外部ページ

フィードバックを選択すると、拡張機能のバージョンと空のテンプレートを入力した GitHub issue の下書きが開きます。閲覧アドレスや診断情報は自動的に添付されません。編集・送信するかどうかはユーザーが決めます。送信後は GitHub が独自のポリシーに従って情報を扱います。その他のリポジトリやドキュメントのリンクは、ユーザーが選択した場合にのみ開きます。フィードバックにはパスワード、トークン、非公開のページ本文、機密パラメーターを含む URL を記載しないでください。

## 権限と限定的な使用

`storage` は上記の設定と端末内のデータに、`contextMenus` は拡張機能の右クリックメニュー操作に使用します。サイトへのアクセス範囲は、閲覧する通常のページでルールを照合し、主要機能を実行するために使用します。サイトを除外したり全体スイッチをオフにしたりできます。ブラウザー内部などの保護されたページには対応していません。拡張機能は `scripting`、`activeTab`、クリップボードの読み書き権限を要求しません。実行するスクリプトはすべて拡張機能に同梱されており、ネットワークからリモートコードを読み込んだり実行したりしません。

EasyCV による Google API から取得した情報の使用と転送は、Limited Use の要件を含む Chrome ウェブストアのユーザーデータポリシーに従います。

## バージョン 1.1.1

1.1.1 のデータ処理は、上記の 1.1.3 と以下の点で異なります。

- サイトの操作記録にはドメインと時刻が、統計には処理したサイトのドメインが含まれる場合があります。これらのデータ、設定、ルールはブラウザーの同期ストレージを使用し、同期できない場合は端末内のストレージに保存されることがあります。
- エラー報告には、完全なページアドレス、エラーメッセージとスタック、ブラウザー情報、時刻、メッセージ送信元の情報が含まれ、ブラウザーアカウントを通じて同期される場合があります。フィードバックの記録もブラウザーのストレージに保存されることがあります。
- 旧バージョンのフィードバックボタンを押すと、現在のページアドレス、ブラウザー情報、時刻が GitHub のフィードバックリンクに入力されます。フィードバックを送信しなくても、リンクを開いた時点で URL とともに GitHub に送られる可能性があります。機密情報のあるページで旧ボタンを使わず、下記の Issues リンクを直接開くことができます。
- このバージョンは `activeTab`、`storage`、`scripting`、`contextMenus`、`<all_urls>` を要求します。拡張機能の設定からデータを削除したり、拡張機能を無効化またはアンインストールしたりできます。同期されたコピーや他の端末上のコピーはブラウザー自体の動作に左右されます。

1.1.3 に更新すると、拡張機能は旧形式のサイト操作記録を新たに追加せず、同意後に上記の方法で旧データを処理します。
