# EasyCV 隱私權政策

[简体中文](../../PRIVACY.md#easycv-隐私政策) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](../../PRIVACY.md#easycv-privacy-policy)

生效日期：2026-11-03 ｜ 適用版本：EasyCV 1.1.1，以及 1.1.3 和之後採用相同資料處理方式的版本

EasyCV 協助你在受限制的網頁上使用複製、貼上、文字選取和右鍵選單。下文先說明 1.1.3 的處理方式；1.1.1 的差異請見「1.1.1 版本」。

## 1.1.3 如何處理資料

EasyCV 沒有開發者伺服器，沒有遙測、廣告或遠端程式碼，也沒有向開發者傳送資料的介面。下列處理都在你的瀏覽器中進行。

### 網頁內容

為偵測並解除網頁對複製、貼上、文字選取和右鍵的限制，擴充功能會處理你造訪的一般網頁之頁面結構、行內事件處理常式和樣式，並在需要時將隨擴充功能封裝的指令碼注入頁面。擴充功能不讀取或儲存剪貼簿內容，也不會將網頁正文、完整瀏覽網址或查詢參數寫入診斷資料。

### 瀏覽紀錄與網站規則

擴充功能會讀取**目前頁面**的網址或網域，以比對你的網站規則與排除清單，並顯示目前頁面狀態。擴充功能不會自行建立瀏覽歷史。

你手動設定的網站規則與排除清單儲存在瀏覽器的 `chrome.storage.sync`，其中包含你輸入的網域。瀏覽器可能依帳號設定將這些設定同步到其他裝置；同步由瀏覽器及其服務提供者處理，不經過 EasyCV 開發者伺服器。

### 使用者活動

舊版會在同步儲存空間中記錄網站互動資料（網域與時間）及各網站的使用次數。1.1.3 不再新增這類紀錄；升級時會將歷史資料移轉到本機備份（見下節），並保留在裝置上直到你手動刪除。

### 啟用次數、診斷與本機副本

- 啟用總次數、當日次數及日期儲存在本機 `chrome.storage.local`，僅供本機顯示；可在設定中關閉計數。這些數字不代表實際複製成功次數或成功率。
- 最近最多 10 筆簡化診斷保存在本機，只包含固定錯誤碼、模組，以及可用時的時間與擴充功能版本；不包含瀏覽網址、網頁正文、剪貼簿內容、例外訊息或堆疊。擴充功能沒有自動上傳診斷的服務。
- 你可以匯出並主動還原保留在本機的舊版設定副本。同步設定優先，不會被本機副本靜默覆蓋。

## 舊版資料與移轉

舊版可能將統計資料（含各網站次數）、網站互動紀錄、錯誤詳情和意見回饋草稿儲存在同步空間中。升級後，只有在你明確同意產品內的資料說明後，擴充功能才會啟用網頁功能並開始移轉：先將歷史統計和互動紀錄備份到本機並驗證，再移除相應的同步副本；舊診斷會經過去識別處理，舊回饋草稿內容會被丟棄。這項移轉不會刪除你的設定及手動規則。同意前，舊資料可能仍保留在同步儲存空間中。

如果本機寫入、驗證或同步清理失敗，未完成的同步副本會保留，設定頁面會提示重試。瀏覽器帳號中的遠端歷史副本，以及仍執行舊版的其他裝置上的副本，無法保證立即刪除。

## 你的選擇

你可以在設定中關閉計數、編輯或刪除網站規則，並使用「設定 → 進階設定 → 清除所有資料」刪除擴充功能設定、規則、本機計數、診斷和歷史備份。關閉計數只會停止新增計數，不會自動刪除已有數字。如需保留設定，清除前請先匯出；設定匯出不包含舊版造訪歷史或診斷。儲存操作失敗時請依介面提示重試。同步資料及其他裝置上的狀態仍受瀏覽器自身同步機制影響。

## 由你主動開啟的外部頁面

點選意見回饋時，擴充功能會開啟 GitHub issue 草稿，預填擴充功能版本與空白範本，不會自動附上瀏覽網址或診斷。是否編輯或提交由你決定；提交後由 GitHub 依其政策處理。其他儲存庫和文件連結只會在你主動點選時開啟。請勿在回饋中填寫密碼、權杖、私人正文或含敏感參數的網址。

## 權限與用途限制

`storage` 用於上述設定及本機資料；`contextMenus` 用於擴充功能的右鍵快捷操作；網站存取範圍用於在你造訪的一般網頁上判斷規則並執行核心功能。你可以將網站加入排除清單或關閉總開關；瀏覽器內部頁面等受保護頁面不受支援。擴充功能不要求 `scripting`、`activeTab` 或剪貼簿讀寫權限；執行的指令碼均封裝在擴充功能內，不會從網路載入或執行遠端程式碼。

EasyCV 對從 Google API 取得的資訊之使用與傳輸，將遵守 Chrome 線上應用程式商店使用者資料政策，包括 Limited Use 要求。

## 1.1.1 版本

1.1.1 的資料處理與上述 1.1.3 並不完全相同：

- 網站互動紀錄可能包含網域和時間；統計可能包含曾處理網站的網域。這些資料、設定及規則使用瀏覽器同步儲存空間；同步不可用時可能寫入本機儲存空間。
- 錯誤報告可能包含完整網頁網址、錯誤訊息與堆疊、瀏覽器資訊、時間和訊息傳送者資訊，並可能透過瀏覽器帳號同步。回饋紀錄也可能儲存在瀏覽器儲存空間中。
- 點選舊版意見回饋按鈕時，擴充功能會將目前網頁網址、瀏覽器資訊與時間預填到 GitHub 回饋連結。開啟連結時，這些資訊可能隨網址傳給 GitHub，即使你沒有提交回饋。請勿在含敏感資訊的頁面使用舊版回饋按鈕；可以直接開啟下方 Issues 連結。
- 該版本要求 `activeTab`、`storage`、`scripting`、`contextMenus` 及 `<all_urls>`。你可以在擴充功能設定中清除資料、停用或解除安裝；瀏覽器同步和其他裝置上的副本仍受瀏覽器自身行為影響。

升級至 1.1.3 後，擴充功能不再新增舊式網站互動紀錄，並在你同意後依上文處理舊資料。
