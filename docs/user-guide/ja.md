# EasyCV ユーザーガイド

[简体中文](../用户使用手册.md) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](./en.md)

このガイドは主に **Chrome ウェブストアで配布されている 1.1.3** を対象としています。2026-11-08 の確認時点で、ストアのパッケージで拡張機能の動作に使うファイルは当時のリポジトリとほぼ一致していましたが、リポジトリの `manifest.json` は引き続き 1.1.2 です。同じバージョン番号でも別のビルドでは動作が異なる場合があります。ブラウザーの拡張機能管理画面で、実際にインストールされているバージョンを確認してください。1.1.1 をお使いの場合は[旧バージョンとの違い](#旧バージョンとの違い)もご覧ください。

## EasyCV の機能

EasyCV は、通常のウェブページで文字選択、コピー、貼り付け、右クリックメニューにかけられた制限の一部を解除するための拡張機能です。全体スイッチ、コピーと貼り付けの個別設定、強力モード、サイトの自動有効化ルール、除外リストを備えています。効果はサイトの実装によって異なり、すべてのサイトでの動作は保証されません。画像やスキャン内の文字も認識できません。

## インストールと言語

1. Chrome で [Chrome ウェブストアの EasyCV ページ](https://chromewebstore.google.com/detail/bnbmgiidicjdbnmkmdnjeelhijnlhnjb)を開き、画面に従ってインストールします。対応する Edge でもストアからインストールできます。他のストアからの拡張機能の許可を求められた場合は、ブラウザーの案内に従ってください。
2. インストール後、ブラウザーの拡張機能メニューから EasyCV を探し、必要に応じてツールバーに固定します。インストール前から開いていた通常のページは再読み込みします。
3. 画面の言語はブラウザーに従い、日本語、簡体字中国語、繁体字中国語、英語に対応します。対応する翻訳がない場合は英語になります。ブラウザーの言語を変更した場合は、案内に従って再起動し、拡張機能の画面を開き直してください。

リポジトリのソースを読み込む場合は、Chrome で `chrome://extensions/` を開き、「デベロッパー モード」をオンにして、「パッケージ化されていない拡張機能を読み込む」から `manifest.json` があるフォルダーを選択します。Edge では `edge://extensions/` を開き、開発者モードをオンにして、パッケージ化されていない拡張機能を読み込む項目を選択します。ボタン名はブラウザーのバージョンによって異なる場合があります。ソースの読み込みはストアからのインストールではなく、ストア版の更新検証にもなりません。

## 使い始める

1. EasyCV のアイコンをクリックし、データに関する説明を確認します。「同意する」を選択した後にページ上の機能を利用できるようになり、旧データがある場合は移行を試みます。「後で決める」を選ぶとウィンドウが閉じるため、後で判断できます。
2. 通常のウェブページを開き、アイコンをクリックして現在の状態を確認します。メインボタンは全体スイッチを操作します。「詳細オプション」では「コピー制限を解除」「貼り付け制限を解除」「強力モード」を個別に変更できます。これらのスイッチは複数のページに影響し、サイトのルールや除外設定も現在のページに適用されます。
3. ページに戻って文字を選択し、実際にコピーして目的の場所へ貼り付けてください。「オン」は設定の状態を示すもので、コピーの成功を保証するものではありません。
4. 「ヘルプ」で内蔵の簡易ガイドを表示できます。「コピー状態を確認」は設定状態のみを読み取り、クリップボードの読み書きや実際のコピーの確認は行いません。

## サイトのルールと除外

- **自動有効化ルール**：「設定 → 自動有効化サイト」を開き、ドメインを入力し、コピーと貼り付けの一方または両方を選んで「追加」をクリックします。リスト内のルールは編集、保存、削除できます。`example.com` のような通常のドメインはそのドメインに一致し、`*.example.com` はサブドメインにのみ一致してルートドメインには一致しません。ルールはそのサイトのコピー・貼り付けの既定値を上書きしますが、全体スイッチや除外設定より優先されません。現在のページから「自動有効化に追加」することもできます。
- **除外サイト**：サイト本来の機能に影響が出る場合は、「設定 → 除外サイト」を開き、ドメインを入力して「追加」をクリックします。`example.com` を除外するとサブドメインも対象です。除外は自動有効化と強力モードより優先されます。既定のリストには `accounts.google.com`、`login.live.com`、`appleid.apple.com` が含まれ、削除することもできます。
- **強力モード**：通常モードで効果がない場合は「詳細オプション」から試してください。ページの操作に影響することがあります。問題が起きたら強力モードをオフにするか、そのサイトを除外して再読み込みしてください。

## データと権限

設定と手動で作成したサイトルールは、入力したドメインを含め、ブラウザーのアカウントを通じて同期される場合があります。有効化回数と簡略化された診断情報は端末内に保存されます。回数はコピーの成功回数ではありません。端末内の有効化回数は既定で記録され、「設定 → 詳細設定」の「この端末での有効化回数を記録（アクセス先のドメインは記録しない）」でオフにできます。同意後、旧データが端末内のバックアップに移行される場合があります。詳細、1.1.1 との違い、削除の制限は[プライバシーポリシー](../privacy/ja.md)をご覧ください。

1.1.3 は設定とデータの保存に `storage`、右クリックメニューの操作に `contextMenus` を使用します。また、通常のウェブページでルールを判定し主要機能を提供するため、`<all_urls>` のサイトアクセスを要求します。クリップボードの読み書き権限は要求しません。サイトアクセス権があっても、ブラウザーの保護されたページは利用できません。

「設定 → 詳細設定」では設定のエクスポートとインポートができます。エクスポートには設定と手動のサイトルールが含まれますが、旧バージョンのサイト訪問記録や診断情報は含まれません。ファイルにドメインが含まれることがあるため、大切に管理してください。「すべてのデータを削除」では、この端末の拡張機能の設定、ルール、回数、診断、旧データのバックアップ、同期ストレージ内の拡張機能データ、同意記録を削除します。他の端末やクラウド上のコピーはブラウザーの同期の仕組みに左右されます。残したい設定は先にエクスポートしてください。削除に失敗した場合は、画面の案内に従って再試行してください。

## よくある質問

**コピーや貼り付けができない場合は？** データの説明に同意したか確認し、全体スイッチ、該当する機能、除外サイト、ブラウザーのサイトアクセス設定を確認して、ページを再読み込みしてからお試しください。必要に応じて強力モードも試せます。ブラウザー内部のページや Chrome ウェブストアなどの保護されたページには対応していません。すべてのサイトの制限解除や、画像・スキャンからの文字抽出もできません。

**有効化後にサイトの動作がおかしい場合は？** 強力モードをオフにするか、そのサイトを除外リストに追加してからページを再読み込みしてください。除外は指定ドメインとそのサブドメインに適用されます。

**コピー後に書式が変わる場合は？** 結果はサイトと貼り付け先のアプリによって異なります。EasyCV は書式の保持を保証しません。

**統計の数字は何を表しますか？** この端末での有効化操作の回数です。コピーの成功回数や成功率ではありません。記録をオフにしても、既存の数値は自動では削除されません。

**アンインストールするには？** ブラウザーの拡張機能管理画面で EasyCV を探し、「削除」を選択して確認します。同期されたデータや他の端末上のコピーはブラウザーの仕組みに左右されます。

## 旧バージョンとの違い

1.1.1 の画面言語は簡体字中国語と英語で、データの処理方法と権限は 1.1.3 と異なります。旧バージョンのサイト操作記録、統計、エラーの詳細がブラウザーの同期ストレージに保存される場合があります。旧バージョンのフィードバックボタンは、現在のページのアドレス、ブラウザー情報、時刻を GitHub のリンクに含めることがあります。送信しなくてもリンクを開いた時点で GitHub に伝わる可能性があります。機密情報のあるページでは旧ボタンを使わず、下記の Issues リンクを直接開いてください。旧データと更新後の移行については[プライバシーポリシー](../privacy/ja.md#バージョン-111)をご覧ください。
