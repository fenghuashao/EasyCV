# EasyCV 使用手冊

[简体中文](../用户使用手册.md) | [繁體中文](./zh-TW.md) | [日本語](./ja.md) | [English](./en.md)

本手冊主要說明 **Chrome 線上應用程式商店發佈的 1.1.3**。2026-11-08 核對時，商店套件的執行檔案與目前儲存庫基本一致，但儲存庫的 `manifest.json` 仍標示為 1.1.2。其他建置即使版本號相同，行為也可能不同；請在瀏覽器的擴充功能管理頁面確認實際安裝的版本。1.1.1 使用者請參閱下方的[舊版差異](#舊版差異)。

## EasyCV 的功能

EasyCV 協助處理一般網頁對文字選取、複製、貼上和右鍵選單的部分限制。它提供總開關、分別控制複製及貼上的選項、強力模式、自動啟用規則和網站排除清單。效果取決於網站實作，無法保證在所有網站生效，也不能辨識圖片或掃描文件中的文字。

## 安裝與語言

1. 在 Chrome 開啟 [Chrome 線上應用程式商店的 EasyCV 頁面](https://chromewebstore.google.com/detail/bnbmgiidicjdbnmkmdnjeelhijnlhnjb)，依提示安裝。相容版本的 Edge 也可從該商店安裝，請依瀏覽器提示操作。
2. 安裝後可從瀏覽器的擴充功能選單找到 EasyCV，並視需要釘選到工具列。重新整理安裝前已開啟的一般網頁。
3. 介面跟隨瀏覽器介面語言，支援简体中文、繁體中文、日本語和 English；沒有對應翻譯時顯示英文。變更瀏覽器語言後，依提示重新啟動，再重新開啟擴充功能頁面。

若要載入儲存庫原始碼，在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 開啟開發人員模式，選擇「載入未封裝項目」，並選取包含 `manifest.json` 的資料夾。載入原始碼不等同於商店安裝或升級驗證。

## 開始使用

1. 點選 EasyCV 圖示並閱讀資料說明。選擇「我同意」後，擴充功能才會啟用網頁功能並開始移轉舊版資料；選擇「稍後決定」可關閉視窗，之後再決定。
2. 開啟一般網頁，點選圖示查看目前狀態。主要按鈕控制總開關；「進階選項」可分別調整「解鎖複製」「解鎖貼上」和「強力模式」。這些開關會影響多個頁面，網站規則與排除設定也會影響目前頁面。
3. 回到網頁選取文字，實際複製並貼到目標位置。「已開啟」只表示相關開關已啟用，不代表複製一定成功。
4. 點選「說明」可查看內建快速指南。「檢查複製狀態」只讀取狀態，不讀寫剪貼簿，也不驗證實際複製結果。

## 網站規則與排除

- **自動啟用規則**：開啟「設定 → 自動解鎖管理」，輸入網域，選擇複製和／或貼上，再點選「新增」。清單中的規則可編輯、儲存或刪除。一般網域如 `example.com` 匹配該網域；`*.example.com` 匹配子網域，不匹配根網域。規則會覆蓋該網站的複製、貼上預設值，但不能繞過總開關或排除清單。也可以在目前網頁使用「加入自動啟用」。
- **網站排除**：如果網站的正常功能受到影響，開啟「設定 → 網站排除」，輸入網域並點選「新增」。排除 `example.com` 也涵蓋其子網域；排除優先於自動啟用和強力模式。預設清單包含 `accounts.google.com`、`login.live.com` 和 `appleid.apple.com`，可自行刪除。
- **強力模式**：一般模式無效時，可在「進階選項」嘗試。它可能影響網頁互動；遇到問題時請關閉強力模式，或排除該網站並重新整理頁面。

## 資料與權限

設定和手動加入的網站規則可能透過瀏覽器帳號同步，規則包含你輸入的網域。啟用次數和簡化診斷存放在本機；計數不代表複製成功次數。預設會記錄本機啟用次數，可在「設定 → 進階設定」中關閉。同意後，舊版資料可能移轉到本機備份。詳細內容、1.1.1 的差異與刪除限制，請見[隱私權政策](../privacy/zh-TW.md)。

1.1.3 使用 `storage` 儲存設定和資料，使用 `contextMenus` 提供右鍵快捷操作，並要求 `<all_urls>` 網站存取範圍，以便在一般網頁判斷規則並提供核心功能。擴充功能不要求讀寫剪貼簿的權限；網站存取範圍不代表受保護的瀏覽器頁面都可使用。

在「設定 → 進階設定」可匯出或匯入設定。匯出內容包含設定與手動網站規則，不包含舊版造訪紀錄或診斷；檔案可能包含網域，請妥善保管。「清除所有資料」會清除本機擴充功能設定、規則、計數、診斷、歷史備份、同步儲存中的擴充功能資料與同意紀錄；其他裝置及雲端副本仍受瀏覽器同步機制影響。清除前請先匯出需要保留的設定。

## 常見問題

**網頁仍無法複製或貼上？** 確認已同意資料說明，檢查總開關、對應功能開關、網站排除及瀏覽器的網站存取設定，重新整理後再試。必要時可嘗試強力模式。瀏覽器內部頁面、Chrome 線上應用程式商店等受保護頁面不支援；本擴充功能也無法處理所有網站限制，或從圖片及掃描文件擷取文字。

**啟用後網站功能異常？** 關閉強力模式，或將該網站加入網站排除，再重新整理頁面。排除範圍為指定網域及其子網域。

**複製後格式不同？** 結果取決於網頁與目標應用程式；EasyCV 不保證保留格式。

**統計數字代表什麼？** 它們是本機啟用操作的次數，不是實際複製成功次數或成功率。關閉計數不會自動刪除已有數字。

**如何解除安裝？** 在瀏覽器的擴充功能管理頁面找到 EasyCV，選擇「移除」並確認。同步資料與其他裝置上的副本仍受瀏覽器機制影響。

## 舊版差異

1.1.1 的介面支援简体中文和英文，其資料處理與權限和 1.1.3 不同；它可能將舊版網站互動、統計與錯誤詳情儲存在瀏覽器同步儲存空間。舊版意見回饋按鈕可能將目前頁面網址、瀏覽器資訊與時間放入 GitHub 連結；即使未提交，開啟連結時這些資訊也可能傳給 GitHub。請勿在含敏感資訊的頁面使用舊版按鈕；可直接開啟下方 Issues 連結。[隱私權政策](../privacy/zh-TW.md#111-版本)說明舊版資料及升級後的移轉方式。
