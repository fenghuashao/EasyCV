# EasyCV 技术架构文档

## 🏗️ 整体架构

### 插件架构模式
采用Chrome Extension Manifest V3架构，包含以下核心组件：

```
EasyCV/
├── manifest.json          # 插件配置文件
├── background/            # 后台脚本
│   └── service-worker.js  # 服务工作者
├── content/              # 内容脚本
│   ├── content.js        # 主要内容脚本
│   └── injector.js       # DOM注入脚本
├── popup/                # 弹窗界面
│   ├── popup.html
│   ├── popup.js
│   └── popup.css
├── options/              # 设置页面
│   ├── options.html
│   ├── options.js
│   └── options.css
├── assets/               # 静态资源
│   ├── icons/
│   └── styles/
└── utils/                # 工具函数
    ├── dom-utils.js
    ├── storage-utils.js
    └── message-utils.js
```

**职责**: 插件生命周期管理、消息处理、状态协调

### 2. Content Script (content/content.js)
**职责**: 页面DOM操作、复制粘贴限制检测与解除、状态同步和队列管理

#### CopyPasteManager

**职责**:
- **DOM操作管理**: 检测和移除页面复制粘贴限制
- **状态同步**: 与Background Script保持状态一致性
- **队列处理**: 管理状态更新队列，确保操作原子性
- **初始化管理**: 处理插件初始化和状态加载

```javascript
// 核心检测和解除模块
class CopyPasteManager {
  constructor() {
    this.isEnabled = false;
    this.forceMode = false;
    this.stateQueue = [];
    this.isProcessingQueue = false;
    this.initializeDetection();
  }
  
  // 检测复制粘贴限制
  detectRestrictions() {}
  
  // 解除限制
  removeRestrictions() {}
  
  // 强力模式处理
  enableForceMode() {}
  
  // 带重试机制的状态加载
  async loadSettingsWithRetry() {}
  
  // 状态更新队列处理
  queueStateUpdate(state) {}
  
  // 队列批量处理
  async processStateQueue() {}
  
  // 原子性状态应用
  applyCurrentState() {}
  
  // 处理Background状态广播
  handleStateBroadcast(message) {}
  
  // 状态监听器管理
  setupStateListeners() {}
}
```

**状态管理特性**:
- **重试机制**: 状态加载失败时自动重试
- **超时处理**: 防止状态加载无限等待
- **状态验证**: 确保接收到的状态数据有效
- **队列机制**: 防止状态更新竞态条件
- **广播监听**: 响应Background的状态变更通知

## 🔍 核心算法设计

### 1. 复制限制检测算法
```javascript
class RestrictionDetector {
  detect() {
    const restrictions = {
      selectstart: this.checkSelectStart(),
      contextmenu: this.checkContextMenu(),
      copy: this.checkCopyEvent(),
      dragstart: this.checkDragStart(),
      cssUserSelect: this.checkCSSUserSelect()
    };
    
    return restrictions;
  }
}
```

### 2. 解除限制算法
```javascript
class RestrictionRemover {
  remove(restrictions) {
    // 按优先级解除限制
    this.removeEventRestrictions(restrictions);
    this.removeCSSRestrictions(restrictions);
    this.removeJSRestrictions(restrictions);
    
    // 验证解除效果
    return this.verifyRemoval();
  }
}
```

### 3. 错误处理
```javascript
class ErrorHandler {
  static handle(error, context) {
    // 记录错误但不暴露敏感信息
    console.error(`[EasyCV] ${context}:`, error.message);
    
    // 用户友好的错误提示
    this.showUserFriendlyMessage(error.type);
  }
}
```
