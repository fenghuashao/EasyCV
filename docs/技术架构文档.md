# EasyCV 技术架构文档

## 🏗️ 整体架构

### 插件架构模式
采用Chrome Extension Manifest V3架构，包含以下核心组件：

```
EasyCV/
├── manifest.json          # 插件配置文件
├── background/            # 后台脚本
│   └── service-worker.js  # 服务工作者
├── content/              # 内容脚本
│   ├── content.js        # 主要内容脚本
│   └── injector.js       # DOM注入脚本
├── popup/                # 弹窗界面
│   ├── popup.html
│   ├── popup.js
│   └── popup.css
├── options/              # 设置页面
│   ├── options.html
│   ├── options.js
│   └── options.css
├── assets/               # 静态资源
│   ├── icons/
│   └── styles/
└── utils/                # 工具函数
    ├── dom-utils.js
    ├── storage-utils.js
    └── message-utils.js
```

## 🔍 核心算法设计

### 1. 复制限制检测算法
```javascript
class RestrictionDetector {
  detect() {
    const restrictions = {
      selectstart: this.checkSelectStart(),
      contextmenu: this.checkContextMenu(),
      copy: this.checkCopyEvent(),
      dragstart: this.checkDragStart(),
      cssUserSelect: this.checkCSSUserSelect()
    };
    
    return restrictions;
  }
}
```

### 2. 解除限制算法
```javascript
class RestrictionRemover {
  remove(restrictions) {
    // 按优先级解除限制
    this.removeEventRestrictions(restrictions);
    this.removeCSSRestrictions(restrictions);
    this.removeJSRestrictions(restrictions);
    
    // 验证解除效果
    return this.verifyRemoval();
  }
}
```

## 🛡️ 安全机制

### 1. 权限最小化原则
- 仅请求必要的浏览器权限
- 限制对敏感页面的访问
- 实施内容安全策略(CSP)

### 2. 数据保护
- 本地存储加密
- 不收集用户隐私数据
- 安全的消息传递机制

### 3. 错误处理
```javascript
class ErrorHandler {
  static handle(error, context) {
    // 记录错误但不暴露敏感信息
    console.error(`[EasyCV] ${context}:`, error.message);
    
    // 用户友好的错误提示
    this.showUserFriendlyMessage(error.type);
  }
}
```
