# EasyCV 代码规范文档

## 📋 总体原则

> "代码是写给人看的，恰好机器可以执行。" - 项目核心理念

- **可读性优先**: 代码应该自解释，减少注释依赖
- **一致性**: 整个项目保持统一的编码风格
- **简洁性**: 避免过度设计，保持代码简洁明了
- **安全性**: 始终考虑安全因素，避免潜在漏洞

### 函数编写规范
```javascript
// ✅ 推荐 - 单一职责，参数清晰
/**
 * 检测页面是否存在复制限制
 * @param {Element} element - 要检测的DOM元素
 * @returns {Object} 检测结果对象
 */
function detectCopyRestrictions(element) {
  if (!element || !element.nodeType) {
    throw new Error('Invalid element provided');
  }
  
  const restrictions = {
    hasSelectStart: hasSelectStartRestriction(element),
    hasContextMenu: hasContextMenuRestriction(element),
    hasCSSUserSelect: hasCSSUserSelectRestriction(element)
  };
  
  return restrictions;
}

// ❌ 不推荐 - 职责不清，参数模糊
function check(el) {
  // 没有参数验证
  // 功能混杂
  // 返回值不明确
}
```

### 错误处理规范
```javascript
// ✅ 推荐 - 明确的错误处理
class CopyPasteManager {
  async enableCopyPaste() {
    try {
      const restrictions = await this.detectRestrictions();
      await this.removeRestrictions(restrictions);
      
      this.logSuccess('Copy-paste enabled successfully');
      return { success: true };
    } catch (error) {
      this.logError('Failed to enable copy-paste', error);
      return { success: false, error: error.message };
    }
  }
  
  logError(message, error) {
    console.error(`[EasyCV] ${message}:`, error);
    // 可选：发送错误报告
  }
}
```

### 异步编程规范
```javascript
// ✅ 推荐 - 使用 async/await
async function loadUserSettings() {
  try {
    const settings = await chrome.storage.sync.get('userSettings');
    return settings.userSettings || DEFAULT_SETTINGS;
  } catch (error) {
    console.error('Failed to load settings:', error);
    return DEFAULT_SETTINGS;
  }
}

// ❌ 不推荐 - 回调地狱
function loadUserSettings(callback) {
  chrome.storage.sync.get('userSettings', (result) => {
    if (chrome.runtime.lastError) {
      callback(null, chrome.runtime.lastError);
    } else {
      callback(result.userSettings || DEFAULT_SETTINGS, null);
    }
  });
}
```

## 📋 Git 提交规范

### 提交消息格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

### 类型说明
- **feat**: 新功能
- **fix**: 修复bug
- **docs**: 文档更新
- **style**: 代码格式调整
- **refactor**: 代码重构
- **test**: 测试相关
- **chore**: 构建过程或辅助工具的变动

### 示例
```
feat(content): 添加强力模式功能

- 实现强力模式的DOM操作逻辑
- 添加强力模式的用户界面
- 完善错误处理机制

Closes #123
```
