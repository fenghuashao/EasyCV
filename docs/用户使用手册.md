# EasyCV 用户使用手册

[简体中文](./用户使用手册.md) | [繁體中文](./user-guide/zh-TW.md) | [日本語](./user-guide/ja.md) | [English](./user-guide/en.md)

本手册以 **Chrome Web Store 分发的 1.1.3** 为主要对象，说明实际可用的功能和限制。2026-11-08 核对时，商店分发包的运行文件与当前仓库基本一致，但仓库的 `manifest.json` 仍标为 1.1.2。其他构建即使版本号相同，行为也可能不同；请在扩展管理页面确认实际安装的版本。1.1.1 用户请参阅下方的[旧版差异](#旧版差异)。

## EasyCV 能做什么

EasyCV 帮助处理普通网页中对文字选择、复制、粘贴和右键菜单的部分限制。它提供全局开关、分别控制复制和粘贴的选项、强力模式、自动开启规则和站点排除列表。效果取决于网站实现，无法保证在所有网站上生效，也不能识别图片或扫描件中的文字。

## 安装和语言

1. 在 Chrome 中打开 [Chrome Web Store 的 EasyCV 页面](https://chromewebstore.google.com/detail/bnbmgiidicjdbnmkmdnjeelhijnlhnjb)，按页面提示安装；也可在兼容的 Edge 中从该商店安装，具体操作以浏览器提示为准。
2. 安装后，可在浏览器的扩展菜单中找到 EasyCV；需要时将其固定到工具栏。刷新安装前已打开的普通网页。
3. 界面跟随浏览器界面语言，支持简体中文、繁體中文、日本語和 English；未匹配的语言回退为英文。更改浏览器语言后，按浏览器提示重启并重新打开扩展页面。

如需加载仓库源码，在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 开启开发者模式，选择「加载已解压的扩展程序」并选择含 `manifest.json` 的目录。源码加载不是商店安装或升级验证。

## 第一次使用

1. 点击 EasyCV 图标，阅读数据说明。选择「我同意」后，扩展才会启用网页功能并开始处理旧版数据；选择「稍后决定」可以关闭窗口，以后再决定。
2. 打开普通网页，点击图标查看当前状态。主按钮控制全局开关；「高级选项」中可分别调整「解锁复制」「解锁粘贴」和「强力模式」。这些开关会影响多个页面，站点规则和排除设置也会影响当前页面。
3. 回到网页选择文字，实际复制并粘贴到目标位置。显示「已开启」只表示相关开关处于开启状态，不代表实际复制一定成功。
4. 点击「帮助」可查看扩展内的快速指南。「检查复制状态」只读取状态，不读取或写入剪贴板，也不验证实际复制结果。

## 站点规则和排除

- **自动开启规则**：打开「设置 → 自动解锁管理」，输入域名，选择复制和／或粘贴，再点击「添加」。列表中的规则可编辑、保存或删除。普通域名如 `example.com` 匹配该域名；`*.example.com` 匹配其子域名，不匹配根域名。规则覆盖该站点的复制、粘贴默认值，但不能绕过总开关或排除列表。也可以在当前网页使用「添加到自动开启」。
- **站点排除**：如果网页的正常功能受到影响，打开「设置 → 站点排除」，输入域名并点击「添加」。排除 `example.com` 同时覆盖其子域名；排除优先于自动开启和强力模式。默认列表含 `accounts.google.com`、`login.live.com` 和 `appleid.apple.com`，可由用户删除。
- **强力模式**：普通模式无效时，可在「高级选项」中尝试。它可能影响网页交互；遇到问题时关闭强力模式，或排除该站点并刷新网页。

## 数据和权限

设置及手工站点规则可能通过浏览器账号同步，规则包含你输入的域名。启用次数和简化诊断存放在本机；计数不代表复制成功次数。默认情况下会记录本机启用次数，可在「设置 → 高级设置」中关闭。旧版数据可能在同意后迁移到本机备份。详细说明、1.1.1 的差异和删除限制见[隐私政策](../PRIVACY.md)。

1.1.3 使用 `storage` 保存设置和数据，使用 `contextMenus` 提供右键快捷操作，并请求 `<all_urls>` 网站访问范围，以便在普通网页判断规则并提供核心功能。扩展不请求剪贴板读写权限；网站访问范围并不意味着受保护页面一定可用。

在「设置 → 高级设置」中可导出或导入配置。配置导出包含设置与手工站点规则，不包含旧版访问历史或诊断；导出文件可能含域名，请妥善保管。「清除所有数据」会清除本机扩展设置、规则、计数、诊断、历史备份及同步存储中的扩展数据，并清除同意记录；其他设备及云端副本仍受浏览器同步机制影响。清除前可先导出需要保留的配置。

## 常见问题

**网页仍不能复制或粘贴？** 确认已同意数据说明，检查全局和对应功能开关、站点排除、浏览器的网站访问设置，然后刷新网页重试。必要时尝试强力模式。浏览器内部页面和 Chrome Web Store 等受保护页面不支持；某些网站限制、图片及扫描件也无法通过本扩展处理。

**启用后网站功能异常？** 关闭强力模式或将该网站加入站点排除，然后刷新网页。排除仅针对指定域名及其子域名。

**复制后格式不同？** 复制结果与网页和目标应用有关；EasyCV 不保证保留格式。

**统计数字是什么意思？** 它们是本机启用操作的计数，不是实际成功复制次数或成功率；关闭计数不会自动删除已有数字。

**如何卸载？** 在浏览器扩展管理页面找到 EasyCV，选择「移除」并确认。同步数据与其他设备上的副本仍受浏览器自身机制影响。

## 旧版差异

1.1.1 的界面支持简体中文和英文，其数据处理及权限与 1.1.3 不同；它可能将旧站点交互、统计和错误详情保存在浏览器同步存储中。旧版反馈按钮可能将当前页面地址、浏览器信息和时间放入 GitHub 链接，即使未提交也可能随打开链接发送给 GitHub。请勿在含敏感信息的网页上使用旧版反馈按钮；可直接访问下方 Issues 链接。[隐私政策](../PRIVACY.md#111-版本)说明旧版数据及升级后的迁移方式。
