# EasyCV 用户使用手册

## 🎯 产品简介

**EasyCV** 是一款专业的浏览器插件，专门用于解除网页复制粘贴限制。无论是学术研究、工作需要还是日常浏览，EasyCV都能帮您轻松获取网页内容，提升工作效率。

### 🌟 核心特性
- ✅ **一键解除**: 快速解除网页复制粘贴限制
- 🔒 **隐私保护**: 绝不追踪浏览历史，绝不收集个人数据
- ⚡ **强力模式**: 应对复杂限制的高级解除功能
- 🎯 **智能识别**: 自动识别并处理各种限制类型
- 📋 **自动开启**: 为常用网站设置自动启用功能
- 🛡️ **安全可靠**: 严格的权限控制，确保浏览安全

## 📥 安装指南

### 系统要求
- **浏览器**: Chrome 88+ / Edge 88+
- **操作系统**: Windows 10+, macOS 10.14+, Linux
- **网络**: 无需联网（本地运行）

### 安装步骤

#### 方法一：Chrome Web Store 安装（推荐）
1. 打开 Chrome 浏览器
2. 访问 Chrome Web Store
3. 搜索 "EasyCV"
4. 点击 "添加至 Chrome"
5. 确认安装权限

#### 方法二：手动安装
1. 下载 EasyCV 安装包
2. 解压到本地文件夹
3. 打开 Chrome 扩展管理页面 (`chrome://extensions/`)
4. 开启 "开发者模式"
5. 点击 "加载已解压的扩展程序"
6. 选择解压后的文件夹

### 安装验证
安装成功后，您会在浏览器工具栏看到 EasyCV 图标：
- 🔴 **红色图标**: 插件未启用
- 🟢 **绿色图标**: 插件已启用

## 🚀 快速开始

### 第一次使用
1. **访问限制网站**: 打开任何有复制限制的网页
2. **点击插件图标**: 在浏览器工具栏点击 EasyCV 图标
3. **启用功能**: 点击 "启用 EasyCV" 按钮
4. **验证效果**: 尝试选择和复制网页文本

### 基本操作流程
```
访问网页 → 点击插件图标 → 启用功能 → 复制内容
```

## 🎮 功能详解

### 主界面功能

#### 状态指示器
- **当前状态**: 显示插件在当前网页的启用状态
- **网站信息**: 显示当前网站域名
- **功能提示**: 显示可用的功能选项

#### 主要按钮

##### 🔄 启用/禁用切换开关
- **功能**: 一键启用或禁用复制粘贴解除功能
- **状态**: 
  - 开启状态 = 插件已启用
  - 关闭状态 = 插件已禁用
- **实时生效**: 切换后立即在当前页面生效

##### ⚡ 强力模式切换开关
- **功能**: 启用高级解除算法，应对复杂限制
- **适用场景**: 
  - 普通模式无效时
  - 网站使用了复杂的限制机制
  - 动态加载内容的网站
- **自动保存**: 设置会自动保存到用户配置

##### 📋 快速操作按钮
- **分析页面**: 检测当前页面的限制类型
- **添加到自动开启**: 将当前网站加入自动启用列表
- **刷新页面**: 重新加载页面以应用设置
- **注意**: 强力模式可能影响网页正常功能

##### ⚙️ 设置按钮
- **功能**: 打开设置页面
- **包含**: 自动开启列表、用户反馈、隐私设置等

### 设置页面功能

## 🔧 高级功能

### 强力模式详解

#### 何时使用强力模式
- 普通模式无法解除限制时
- 网站使用了复杂的JavaScript保护
- 动态内容加载的单页应用
- 使用了第三方限制插件的网站

#### 强力模式原理
- **深度DOM扫描**: 检测所有可能的限制机制
- **事件重写**: 重新定义页面事件处理
- **样式覆盖**: 强制覆盖CSS限制样式
- **脚本注入**: 注入解除限制的JavaScript代码

#### 使用注意事项
⚠️ **重要提醒**:
- 强力模式可能影响网页正常功能
- 某些交互功能可能暂时失效
- 建议完成复制后关闭强力模式
- 如遇问题请刷新页面恢复

### 自动开启功能

#### 智能识别
EasyCV 会自动识别以下情况并提示启用：
- 检测到复制限制的网站
- 用户尝试复制但被阻止
- 右键菜单被禁用的页面

#### 白名单管理
- **自动添加**: 启用功能时询问是否加入自动开启列表
- **批量导入**: 支持从文件导入网站列表
- **分类管理**: 按网站类型分类管理

### 站点排除功能（1.1.0 新增）

#### 什么时候需要排除
EasyCV 默认在所有网站生效。个别网站的正常功能可能与解除限制冲突（例如某些播放器的定制右键菜单），这时可以把该网站加入排除列表——EasyCV 将在该站**完全休眠**，不再进行任何解除操作。

#### 如何使用
1. 打开扩展「设置」→ 左侧「站点排除」
2. 输入域名（如 `bilibili.com`，其所有子域名一并生效）并点击「添加」
3. 再次访问该网站时 EasyCV 自动停用；从列表删除后立即恢复

#### 内置保护
列表默认包含常见账号登录页（accounts.google.com 等），解除脚本不会在高价值账号页面运行。内置条目可按需删除。

> 排除列表的优先级高于全局开关、自动开启列表与强力模式；它随设置同步，并包含在设置的导出/导入中。

| 权限 | 用途 | 必要性 |
|------|------|--------|

| `storage` | 本地数据存储 | 必需 - 保存用户设置 |
| `scripting` | 注入解除脚本 | 必需 - 执行解除操作 |

## ❓ 常见问题

### 功能相关

**Q: 为什么有些网站无法解除限制？**
A: 可能原因：
- 网站使用了特殊的保护机制
- 尝试启用强力模式
- 检查浏览器是否阻止了插件运行
- 联系我们反馈具体网站

**Q: 强力模式会影响网页功能吗？**
A: 可能会影响：
- 某些交互按钮可能暂时失效
- 动态内容加载可能受影响
- 建议复制完成后关闭强力模式

**Q: 如何添加网站到自动开启列表？**
A: 两种方法：
1. 在网站上启用功能时选择 "记住此网站"
2. 在设置页面手动添加网站域名

### 技术相关

**Q: 插件支持哪些浏览器？**
A: 目前支持：
- Chrome 88 及以上版本
- Edge 88 及以上版本
- 计划支持 Firefox（开发中）

**Q: 插件会影响浏览器性能吗？**
A: 不会：
- 仅在需要时激活
- 内存占用小于 10MB
- 不会常驻后台运行

**Q: 如何卸载插件？**
A: 卸载步骤：
1. 打开浏览器扩展管理页面
2. 找到 EasyCV 插件
3. 点击 "移除" 按钮
4. 确认卸载

### 故障排除

**Q: 插件图标显示但点击无反应？**
A: 解决方法：
1. 刷新当前页面
2. 重启浏览器
3. 检查插件是否被禁用
4. 重新安装插件

**Q: 复制的内容格式丢失？**
A: 这是正常现象：
- 插件主要解除文本复制限制
- 格式信息可能无法完全保留
- 建议复制后在目标应用中重新格式化
