## Traceability / 追溯方式

The nine `EASYCV-…` reports formerly at the repository root are now under `docs/reports/2026-11`. The former root version plan is under [planning](../planning/EASYCV-NEXT-VERSION-PLAN.md). The August reports formerly under `docs` are now grouped by month above. Earlier logs, proposals and analysis pages are under [archive](../archive/).

[Raw evidence](../evidence/) retains its existing file paths and content, including captured commands, hashes and references to historical locations. Report Markdown links have been rebased to the new layout; recorded command lines and acceptance conclusions remain historical. Git history also preserves the original locations.
