# EasyCV 对外文档核对记录（2026-11-08）

## 范围和依据

本次整理仓库首页、用户手册、隐私政策、面向用户的更新记录和 Wiki 入口草稿，支持简体中文、繁體中文、日文和英文。开发计划、验收原始报告及内部技术资料保持历史记录，不逐份翻译。

核对依据包括当前仓库 manifest、语言包、弹窗与设置页面、站点规则和存储实现；以及 2026-11-08 未登录访问的 [Chrome Web Store 页面](https://chromewebstore.google.com/detail/bnbmgiidicjdbnmkmdnjeelhijnlhnjb)和[官方更新接口](https://clients2.google.com/service/update2/crx?response=redirect&prodversion=156.0.8078.79&acceptformat=crx3&x=id%3Dbnbmgiidicjdbnmkmdnjeelhijnlhnjb%26installsource%3Dondemand%26uc)。商店页面直接请求显示 1.1.3、更新日期 2026-11-04、四种语言；页面缓存可能较旧。以 `en`、`zh-CN`、`zh-TW` 和 `ja` 分别请求时，均返回对应语言的商店介绍，功能、同意、同步及本机数据的要点一致。官方更新接口返回的 1.1.3 CRX 的 SHA-256 为 `a27edff79eb87f581dba60a06d439053339339243bf303d999e91359ccfa816e`。该包 41 个文件中有 34 个与仓库文件逐字节一致；manifest 和四个语言包不完全相同，另外两个是商店产物元数据。四个语言包的消息差异均仅为扩展简介；manifest 的版本为 1.1.3，附有商店 `update_url`，其余清单项与仓库一致。仓库 manifest 仍为 1.1.2。该核对不等同于已安装用户的同 ID 升级验收。

## 主要更正

- 删除旧手册中「全部设置只在本地」「不收集任何个人数据」、不存在的快捷键、列表批量导入／分类、固定内存占用及“1.0.0 即将发布”等错误或缺乏证据的说法。
- 四语言手册以商店 1.1.3 为主要对象，解释数据说明、同步与本机数据、规则优先级、成功效果的限制和旧版反馈风险。
- 隐私政策保留 1.1.1 与 1.1.3 的不同处理方式，补齐繁体中文、日文及语言导航。隐私政策生效日期与既有中文和英文政策保持一致。
- 根目录更新日志补充已分发的 1.1.3，保留 1.1.2 本机候选和更早工程记录；其他三种语言提供相同版本范围的用户摘要。
- 核对时公开 Wiki 的首页和 `User Guide` 仍含「所有数据仅存本地」等旧说法；已在 `docs/wiki-draft/` 准备以仓库正文为入口的替换草稿，后续更新以公开 Wiki 为准。

## 验证结果

- `npm run docs:check` 和 `git diff --check` 通过；另检查 17 个相关 Markdown 文件中的 170 个本地或计划发布的仓库链接及标题锚点，均能在本地解析。四种语言的导航、版本范围和用户手册章节数通过结构核对。
- `npm test` 首次因现有 `node_modules` 缺少锁定依赖 `yazl` 而无法加载一组打包测试。在临时目录按锁文件安装依赖，通过 `NODE_PATH` 使用该隔离依赖后，完整单测 152/152 通过；未改变仓库依赖配置或现有安装。
- 商店四语言介绍和分发包为只读核对；本次未进行真实用户的浏览器安装、升级、复制体验或外部母语审校。

## 边界和维护

初次核对及草稿阶段没有操作商店后台、推送仓库或发布 Wiki；本记录保留当时的验证边界。公开内容以实际线上页面为准，仓库内修改不会自动修正 Wiki。隐私政策和商店声明的公开更新应核对最终版本及文本；语言版本尚未经过外部母语审校。
