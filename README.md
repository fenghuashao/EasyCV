# CopyUtil - 复制粘贴限制解除插件

一个强大的Chrome浏览器扩展，用于解除网页的复制粘贴限制，提升用户体验。

## 功能特性

### 核心功能
- 🚫 **解除复制限制** - 突破网页禁止复制文本的限制
- 📋 **解除粘贴限制** - 允许在禁止粘贴的输入框中粘贴内容
- ⚡ **智能检测** - 自动识别并处理各种限制机制
- 🔧 **强制模式** - 针对顽固限制的强制解除模式
- 🎯 **精准控制** - 独立控制复制和粘贴功能

### 高级特性
- 🌐 **自动开启** - 支持为特定网站配置自动开启
- 📊 **使用统计** - 记录使用情况和成功率
- 🔄 **实时同步** - 多窗口状态实时同步
- 💾 **数据持久化** - 设置和统计数据本地存储
- 🎨 **现代界面** - 简洁美观的用户界面

## 技术架构

### 1. 模块化设计
- **Background Script**: 负责状态管理、消息路由和数据持久化
- **Content Script**: 负责页面检测、限制解除和用户交互
- **Popup Interface**: 提供用户控制界面和状态显示
- **Options Page**: 提供详细设置和配置选项

### 2. 状态管理系统
- **集中式状态管理**: 所有状态由Background Script统一管理
- **实时状态同步**: 使用消息广播机制实现多窗口同步
- **乐观更新策略**: UI立即响应用户操作，后台确认状态变更
- **错误恢复机制**: 操作失败时自动回滚UI状态

### 3. 消息通信架构
- **统一消息接口**: 封装Chrome扩展API，提供一致的通信接口
- **错误处理机制**: 完善的错误捕获和处理逻辑
- **超时保护**: 防止消息通信阻塞
- **重试机制**: 自动重试失败的操作

### 4. 数据存储策略
- **分层存储**: 区分用户设置、统计数据和临时状态
- **版本管理**: 支持数据结构升级和迁移
- **性能优化**: 批量操作和缓存机制
- **数据完整性**: 校验和备份机制

## 安装说明

### 开发环境安装
1. 克隆项目到本地
2. 打开Chrome浏览器，进入扩展管理页面 (chrome://extensions/)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目根目录

### 生产环境安装
- 从Chrome Web Store安装（即将上线）

## 使用方法

1. **基础使用**
   - 点击浏览器工具栏中的插件图标
   - 根据需要开启复制或粘贴功能
   - 在目标网页上正常进行复制粘贴操作

2. **高级设置**
   - 右键点击插件图标，选择"选项"
   - 配置自动开启网站列表
   - 调整检测敏感度和其他参数

3. **快捷操作**
   - 使用快捷键快速开启/关闭功能
   - 双击插件图标快速切换模式
